# 🌤️ Weather App

A responsive weather application built with **HTML, Tailwind CSS, and Vanilla JavaScript**.  
The app uses a weather API to fetch and display weather information for searched cities.

## 📖 About The Project

This project was built as a **Frontend Practice Project** to move beyond static web pages and practice building a functional application with real-time data.

Users can search for a city and get its current weather information through an external API. The application handles the API request asynchronously and dynamically updates the interface based on the received data.

The project focuses on practicing **API integration, asynchronous JavaScript, DOM manipulation, and responsive UI development**.

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current weather information
- 🌤️ Show weather conditions dynamically
- 📍 Display the searched city
- ⚡ Fetch data from an external weather API
- 🔄 Handle asynchronous requests with `async/await`
- ❌ Display an error message when a city cannot be found or a request fails
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎨 Responsive UI built with Tailwind CSS

## 🔄 How It Works

1. The user enters a city name in the search field.
2. JavaScript sends a request to the weather API using `fetch()`.
3. The request is handled asynchronously using `async/await`.
4. The API returns weather data in JSON format.
5. JavaScript extracts the required information from the response.
6. The UI is dynamically updated with the weather information.
7. If the city cannot be found or an error occurs, an appropriate message is displayed.
